# 💕 心心相印 · HeartSync

情侣日常记录与同步小程序 —— 单文件 HTML 移动端 Web 应用。

## 功能

| 模块 | 说明 |
|------|------|
| 🏠 首页 | 在一起天数、双方心情、时间线记录（文字/图片/视频）、评论回复 |
| 👫 我们 | 配对密匙、自定义纪念日倒计时、连续打卡 |
| ➕ 记录 | 发布文字/图片/视频动态，选择心情标签 |
| 💬 留言 | 实时留言板，输入栏始终沉底，键盘自适应 |
| 📋 任务 | 互相分配任务，完成后上传图片/视频凭证 |
| 👤 我的 | 昵称/头像编辑、性别（注册时选定）、经期日历与预测、主题切换、退出登录 |
| 🔐 登录注册 | 密码/短信双模式登录，5步注册向导含性别选择（模拟） |
| ✨ 启动页 | 优美动画启动屏 |
| 🎨 主题 | 4套配色（粉红/星空/森林/海洋） |

## 运行

```bash
# 任意静态服务器即可，例如：
cd couple-app
python -m http.server 8765

# 浏览器打开
http://localhost:8765/index.html
```

也可直接用浏览器打开 `index.html`。

## 技术

- 纯前端，单文件 HTML（CSS + HTML + JS 内嵌）
- 无框架、无构建工具、无后端
- `localStorage` 持久化
- `visualViewport` API 移动端键盘适配
- CSS 自定义属性实现多主题
- 移动优先，`max-width: 430px`，`100dvh` 动态视口

## 模拟账号

所有登录均为前端模拟：
- **密码登录**：任意 11 位手机号 + 任意密码 + 匹配验证码
- **短信登录**：手机号 + 验证码 + 短信码 `123456`
- **注册**：5 步向导，第 5 步选择性别（选定后不可修改）
